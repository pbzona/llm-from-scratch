# Sample text

`the-verdict.txt` is Edith Wharton's public-domain short story “The Verdict.”
It is the sample used in Chapter 2 of Sebastian Raschka's
*Build a Large Language Model (From Scratch)*.

Downloaded without modification from the
[book's repository](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/the-verdict.txt).
The story is also available on
[Wikisource](https://en.wikisource.org/wiki/The_Verdict).
